# Jeevithkumar R | Software Developer

I build and run complete web products, from the client call to the live server. I also build AI
agents and dashboards.

I lead a five-person development team, run six production platforms and have shipped 50+
websites. I work on the frontend, the backend, the database and the server, so nothing gets lost
between a requirement and something running in production.

Open to full-time roles — remote or on-site. Based in Tamil Nadu, India.

---

## What I do

- **Build web products end to end.** Requirements, database design, backend APIs, frontend, and
  the server everything runs on.
- **Build AI agents.** Retrieval pipelines, tool calling, routing, streaming responses, an admin
  portal to manage what the agent knows.
- **Build dashboards.** Turning operational data into screens people can act on.
- **Run the infrastructure.** Linux, Nginx, Apache, Docker, deployments, SSL, DNS, backups.
- **Connect business systems.** CRM integrations, form handling, lead capture, attribution and
  reporting.
- **Lead a team.** Task assignment, code review and delivery ownership for five developers.
